# Third-party software

The offline icon bundle `vendor/lucide.js` is the unmodified minified UMD build of
**Lucide 1.8.0**, copied from the installed runtime package. Project:
https://lucide.dev/ . Package: https://www.npmjs.com/package/lucide .

Lucide uses the ISC license, with specified Feather-derived icons under MIT.
The complete distributed license and attribution are preserved verbatim in
[vendor/LICENSE-lucide](vendor/LICENSE-lucide).

The interface uses the browser's native APIs. There are no application framework
or Python package dependencies.

# Source-library reconciliation | 12 October 2026

**Status:** Library consolidation complete. Public artwork import requires verified original-byte access and SHA-256 comparison; **no missing image has been certified or uploaded by this change**.

Project-managed original attachments have not been destroyed. This source inventory is **not** a count of missing public repository assets.

## Current public repository baseline

The pre-existing recovered public library already documents 232 unchanged source assets, including 187 images, and two sanitized metadata derivatives. Preserve its manifest, SHA256SUMS, source-specific caveats and original bytes. The established outstanding evidence gaps remain **R24, R25, R26** (unmapped) and eight historical production/animation binary records listed as unavailable in `resources/character-library/Missing-Resources.json`. No new source is being asserted to fill those gaps.

## Import gate for additional images

1. Access actual full-resolution source bytes, never screen previews or re-encoded exports. Some supplementary project-managed originals could not be exported through the available interface.
2. Verify each candidate's exact SHA-256 against the existing public manifest and SHA256SUMS; distinguish byte-identical duplicates from genuinely different variants.
3. Run the same privacy/sanitization review used for the recovered public library. Do not import private recovery bundles, unrelated artifacts or service/account metadata.
4. Preserve original reference identifiers **R01–R34 and C01–C15**, parent/crop relationships and known defects. Do not silently fill R24–R26 or invent approvals. New experiments remain experimental until feature-specific creator approval.
5. After actual asset changes, update the asset manifest and checksums in one consistent transaction; rebuild Pages gallery/index and verify image paths, desktop/mobile rendering and validation tests.
6. Submit a reviewable pull request; no automatic merge or publication.

## Character authority is unchanged

The Character Design Brief remains the governing appearance specification; locomotion and acting stay separate, and the Master Character Prompt remains subordinate. The baseline outfit remains the dusty-pink skirt with dark brown waistband; organic-membrane variants are alternative **experiments**, not the default. R08 for approved proportions/lichen, R11 for point geometry and the latest written broad, shallow fly-agaric cap rule retain feature-specific priority. Ranking a complete sheet does not make all of its visible features canon.

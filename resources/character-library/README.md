# Myca public repository resources

This public recovery subset contains 237 unchanged original assets and two clearly labeled sanitized metadata derivatives. No artwork bytes were changed. Current filename aliases, hashes, sizes, feature scopes, defects, and derivative provenance are in manifest.json. The unchanged derivative sources are retained in the owner archive. R01–R34 and C01–C15 are retained; R24–R26 remain missing/unmapped. Membrane experiments are provisional and distinct from baseline. Inclusion does not mean whole-image approval.

Private discussion URLs, owner service/Page IDs, unrelated active-pet metadata, internal paths and redundant nested ZIPs are omitted from the current public tree. Excluded originals remain in the owner ZIP. The two derivatives are identified by original_bytes:false and source hashes, not presented as unchanged originals. Earlier public commits retain the two unsanitized documents; Git history was not rewritten. Unchanged historical documents may use prior-layout relative links; resolve their targets through filename aliases.

resources/ uses hash directories to prevent filename collisions and duplicate content. Page-only files use documented Page-label filenames when original filenames were unavailable. SHA256SUMS verifies all included bytes.

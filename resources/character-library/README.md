# Myca public repository resources

These original artwork bytes and project documents form the sanitized repository subset of the recovery archive. Original filename aliases, hashes, sizes, feature approvals and defects are in manifest.json. R01–R34 and C01–C15 are retained; R24–R26 remain missing/unmapped. Membrane experiments are provisional and distinct from baseline. Inclusion does not mean whole-image approval.

Private discussion URLs, owner file IDs, internal paths and redundant nested ZIPs are omitted. Some original manifests containing those details stay only in the owner ZIP; their artistic content is represented by this additive manifest. Original retained documents are unchanged and may use prior-layout relative links; resolve their targets through filename aliases.

resources/ uses hash directories to prevent filename collisions and duplicate content. Page-only files use documented Page-label filenames when original filenames were unavailable. SHA256SUMS verifies all included bytes.

# Public Myca resource subset

232 unchanged originals and two explicitly labeled sanitized metadata derivatives. All 187 image assets are byte-identical to the audited recovery. Original affected documents are retained in a private owner archive outside this repository. Derivatives are not aliases of their originals. The manifests retain source SHA-256 hashes, reference limitations and experimental classifications. No private archive location or identifier is published.

Use [Index.md](Index.md) and [Asset-Catalog.md](Asset-Catalog.md) for repository navigation. Historical source documents retain old relative links; these are audit snapshots, not the navigation surface. Read [Sanitation-Report.md](Sanitation-Report.md) for audit scope and residual exposure.

Storage filenames are Windows-compatible. Previous public source labels remain descriptive aliases, including labels containing colons; they are not additional files. Artwork bytes and SHA-256 hashes are unchanged.
